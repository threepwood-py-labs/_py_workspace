## Per-Project Details

### arr-helper-ui — 8/10
Sonarr/Radarr media library management toolkit (PySide6 GUI + CLI).
- Unresolved merge conflict: `uv.lock.rej` present — lockfile inconsistent, builds may not be reproducible
- Heavy `cast()` usage on JSON API responses without explicit validation
- Integration tests sparse for media quality checker logic
- Suggestions: resolve lockfile conflict; add integration tests for checker; add structured logging in error catch-alls

### git-statuz — 8.5/10
PySide6 desktop viewer for Git status, commit history, and diffs.
- Windows `creationflags` pattern duplicated across multiple subprocess calls
- No tests for path edge cases (spaces, UNC paths, symlinks)
- No distinction in error messages between "not a git repo" and other git failures
- Suggestions: extract `_run_git_subprocess()` helper; add edge-case path tests; improve `GitCommandError` diagnostics

### mp3gain-gui-py — 8.5/10
PySide6 port of MP3Gain GUI with parallel process pool and legacy CLI surface.
- Dead code (`vulture`) and complexity checks are advisory-only in CI (`continue-on-error: true`)
- High cyclomatic complexity suspected in `legacy_cli_parser.py` and `legacy_cli_runtime.py`
- Suggestions: make dead code and complexity checks blocking; refactor high-complexity CLI functions; add runtime Python version pre-flight check

### pdf-search-downloader-ui — 8/10
PySide6 desktop app for browser-driven PDF search/download with Playwright automation.
- No custom `typings/` stubs directory (unlike other projects)
- `browser_session.py` is 31K characters handling multiple concerns
- Fewer test files than comparable projects
- Suggestions: add `typings/` directory for Playwright stubs; split `browser_session.py`; increase test coverage and make dead code checks blocking

### prowlarr-ui — 9/10
PySide6 desktop GUI for searching Prowlarr indexers with Everything integration.
- Dead code and complexity checks advisory-only
- GUI tests sparse relative to unit tests
- Suggestions: make `vulture` and complexity checks blocking; expand pytest-qt GUI test coverage; document threading/signal architecture in README

### qbiremo-enhanced — 9/10
Advanced qBittorrent PySide6 client with controller pattern and task queues.
- Dead code and complexity checks advisory-only
- `MEMORY_SPEC.md` referenced in docs but appears to be a stub
- Suggestions: make `vulture` and complexity checks blocking; complete `MEMORY_SPEC.md`; add more unit tests for config validation and model contracts

### threep-commons — 9/10
Shared runtime and utility library for the workspace (v0.3.1).
- No coverage badge in README despite 80% target configured
- Public API docs incomplete (TODO in README)
- Suggestions: add Codecov badge; expand API documentation; consider Python 3.14+ in test matrix for forward compatibility

### video-duperz — 8.5/10
PySide6 app for perceptual duplicate video detection using dhash fingerprinting.
- Functions with 9+ parameters (e.g. `_analyze_file_with_probe`) — should use dataclass options
- DB schema undocumented despite multi-table design with WAL pragmas
- 5-mixin database composition pattern increases cognitive load
- Suggestions: introduce options dataclasses for long signatures; document DB schema; add performance benchmarks to CI

### web-pagez-to-pdf — 9.5/10
PySide6 app for browser window capture and multi-format document export.
- No `py.typed` marker verification in pre-commit
- Windows-specific Win32/ctypes usage undocumented for new contributors
- Suggestions: add `py.typed` check; add `WINDOWS_SETUP.md` for Win32 dependencies; document which test markers run in CI vs locally

### _py_template — 9/10
Copier template for standardized Python 3.13 projects across the workspace.
- No automated drift detection for child projects after template updates
- ADRs (architecture decision records) not documented
- Suggestions: add periodic GH workflow for drift detection; document ADRs for tooling choices (Hatch vs Poetry, basedpyright vs mypy, src/ layout); strengthen policy checks for conftest.py fixture validation

### many-panelz-explorer — 8.9/10
Multi-panel Windows file explorer with tabbed navigation (PySide6).
- 3 files need `ruff format`: `section_appearance_panels.py`, `panel_widget.py`, `ui/window/actions.py`
- Policy violations: 7 oversized files (>600 lines), 6 oversized classes (>450 lines), 9 oversized functions (>120 lines)
- See REFAC.md for full structural refactoring details

## Top 3 Workspace-Wide Recommendations

1. **Make dead code and complexity checks blocking** — change `continue-on-error: true` to `false` in CI across `mp3gain-gui-py`, `prowlarr-ui`, `qbiremo-enhanced`, and `pdf-search-downloader-ui`. Violations currently accumulate invisibly.

2. **Resolve `arr-helper-ui` lockfile conflict** — `uv.lock.rej` means the lockfile is in an inconsistent state; builds could be non-reproducible.

3. **Add drift detection to `_py_template`** — a periodic GH workflow comparing child projects against template standards would catch gradual divergence before it becomes expensive to fix.
